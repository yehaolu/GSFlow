# GSFlow project page

Static, dependency-free project page for:

> GSFlow: Video Rendering Acceleration for 3D Gaussian Splatting via Geometry Pixel Flow

## Preview locally

From this directory, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a GitHub repository, for example `GSFlow`.
2. Add all files in this directory to the repository root and push them to the default branch.
3. Open **Settings > Pages** in the repository.
4. Choose **Deploy from a branch**, select the default branch and `/ (root)`, then save.
5. The page will be available at `https://<username>.github.io/GSFlow/` after the first deployment completes.

All links are relative, so the page works both at a user site root and in a project subdirectory. The videos are stored directly in the repository and each file is below GitHub's 100 MB per-file limit.
